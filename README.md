# VIVI Telegram Bot 🚫 Deprecated

> **Status: Deprecated**  
> This repository is no longer actively maintained. Kept public for portfolio and historical reference.

Telegram trading bot for **Base**, built with TypeScript and Telegraf.

It allowed users to trade tokens, manage wallets, send/tip using Telegram usernames, and interact with the fee-on-swap contracts — all inside Telegram group chats.

Used by **100+ communities** and generated **600+ ETH** in organic trading volume.

## Key Features

- Trade any token on Base from Telegram
- Wallet creation and management inside the bot
- Send / tip / transfer by Telegram username
- Multi-send and batch transactions
- Referral and points system
- Integration with custom fee-on-swap wrappers

## Tech Stack

- TypeScript
- Telegraf
- Prisma + PostgreSQL
- Redis
- Ethers.js / Base
